# To-Do List Application

A simple command-line to-do list application written in Python.

## Features

- View all tasks
- Add new tasks
- Delete tasks
- Simple and intuitive menu-driven interface

## Requirements

- Python 3.x

## Usage

Run the application with:

```bash
python3 todo.py
```

### Menu Options

1. **View tasks**: Display all current tasks
2. **Add a task**: Add a new task to your list
3. **Delete a task**: Remove a task from your list
4. **Exit**: Close the application

## Example

```
--- TO-DO LIST ---
1. View tasks
2. Add a task
3. Delete a task
4. Exit
Choose an option (1-4): 2
Enter a new task: Buy groceries
Task added successfully.
```
